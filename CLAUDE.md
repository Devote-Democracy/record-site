# record-site: notes for agents

- Public site and (soon) public repo. Nothing private here: no internal URLs, keys, paths or user data.
- All data comes from the public log through `@devotedemocracy/record-verifier`; never add a back end
  or a second data source the visitor can't check.
- Plain, honest copy: don't say "blockchain voting". Say what is and isn't proven (see How it works).
- Fonts: Raleway (body); titles Recoleta once its webfont licence is confirmed (serif fallback until then).
- Test with `npm run demo`; check phone width (375px) and dark mode before committing.
